# JSON / JSONC (`org.koren.json`)

JSON and JSONC language support via vscode-json-language-server.

- **Supported extensions:** `.json`, `.jsonc`
- **Declared optional tools (via Tool Manager):** `vscode-json-language-server`

> External tools are not bundled with this extension; Koren's Tool Manager registers them so you can detect, configure, or install them on demand.
